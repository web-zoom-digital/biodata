# BioCraft: marriage biodata maker

A private, no-signup marriage biodata maker built with Next.js (App Router), TypeScript and Tailwind CSS v4.
Fill in details, pick a template, see a live A4 preview and download a PDF, PNG or JPEG. There is no backend: the draft lives in the visitor's browser and files are created on their device.

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
```

Other scripts:

| Command | What it does |
|---|---|
| `npm run build` | Production build (all pages are static) |
| `npm start` | Serve the production build |
| `npm run lint` | ESLint |
| `npm run typecheck` | Generates route types, then runs `tsc --noEmit` |

Requires Node 20.9 or newer. Fonts are bundled in `src/fonts`, so builds need no network access to Google Fonts.

## Before you go live

1. Set your domain: create `.env.local` with `NEXT_PUBLIC_SITE_URL=https://your-domain.com` (used for canonical URLs, sitemap and structured data).
2. Edit `src/config/site.ts`: brand name, contact email (currently `hello@biocraft.example`), social links, navigation.
3. Have the **Privacy** and **Terms** pages reviewed for your jurisdiction. They are a starting draft written for this app's behaviour (no accounts, local storage only). If you add analytics, ads or a backend, update them.
4. Optionally add real photography, see `docs/IMAGES.md`.

## What is where

```
src/
  app/            Routes. (site)/ has the marketing pages with navbar + footer; create/ is the full-screen editor
  components/     ui, layout, home, editor, forms, preview, templates, blog, faq, seo
  config/site.ts  Brand, URL, nav, footer, storage key (single place to rebrand)
  data/           Sample biodata, form suggestions, FAQs, home copy, template filters
  lib/            biodata view-model, zod schema, storage, seo helpers, content loader, export pipeline
  store/          Zustand stores (biodata, editor UI)
  templates/      Template registry + one folder per template + shared primitives
  types/          BiodataData and template types
content/          Markdown for blog/ and guides/ (frontmatter + body)
docs/             Architecture, templates, export, SEO, images, change guide
```

## Known limitations

- **PDF text is not selectable.** *Download PDF* embeds a ~300 dpi page image. *Print or save as PDF* (browser print dialog) gives selectable text.
- **Long PNG/JPEG** exports come out as one tall image; only the PDF is split into A4 pages.
- **Decorative frames** (Royal Heritage, Traditional Gold) are continuous, so on a multi-page biodata they are cut at page boundaries.
- **Non-Latin text** (e.g. Hindi) is drawn with the device's font, so it can look different between devices. Built-in field labels are English.
- Exports were tested in headless Chromium. Test on real iPhone Safari before launch.
- A draft is stored per browser and device. Clearing site data removes it.

## Tech notes

Next.js 16 changed some APIs (async `params`, generated `PageProps`/`LayoutProps` types). Route types are generated by `next dev`, `next build` or `npm run typecheck`.
